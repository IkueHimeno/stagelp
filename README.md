# Stage LP
舞台公演を想定したランディングページ（LP）です。
本プロジェクトでは私が実際にプロデュースした舞台公演の情報構成をベースに制作しております。  
公演情報・キャスト一覧・チケット案内など、必要な要素を整理し、ユーザーが見たい情報を迷わずに閲覧できる構成を目指しています。
